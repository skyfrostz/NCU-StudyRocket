# StudyRocket 原生界面与独立任务修复

日期：2026-11-12。本文区分源码、自动检查、运行观察和用户确认；不以构建成功替代真机体验验收。

## 变更

- Mac：课表日期采用系统日历弹出层；按用户最新要求仅保留周视图，窄窗横滚限制在网格内部。活动编辑分清既有课表与可编辑活动，无改动不生成保存。宽窄窗、全屏聊天、周计划操作栏、资料分栏、设置和阅读宽度统一。
- 字体：用户体验全宋体后确认改为“原生系统字体为主”。两端标题、控件、课表、聊天正文与输入均跟随系统字体；首页诗句可单独保留宋体，系统图标和代码保留语义字体。最终原生字体构建与安装状态见下表，不把之前全宋体包当作最终交付。用户气泡靠右，内部多行文字左对齐。
- 流式回复合并短时间内的显示更新，结束时补齐最终内容；显示合并不截断模型文本。减少逐 token 的滚动与 Markdown 重建。取消和迟到 SSE 按连接及回合隔离。
- 手机失败请求提供就地重试。未知提交结果先查权威记录，保留原操作编号；不盲目重发。刷新定位最新动态，同时尊重用户在等待期间主动浏览历史。空响应不清空已有对话。
- 草案默认显示变更片段；宽屏分栏，窄屏及辅助字号上下对照。完整文件仍可展开。同步冲突使用“本机草稿 / 当前云版本”标签，保持原始基线及确认语义。
- 任务联动以“让 AI 整理”为主要入口，手工管理置于次级菜单。保留未发送草稿，不自动发送或确认。模型读取完整任务身份后提出草案；新增联动不能伪造完成状态或删除已有身份。
- 独立任务规则纳入云端与旧 Host 的共同提示，规范使用单元格内的独立任务分隔。保留原日期、标题、稳定身份和历史完成事实；拆分不推断两项都已完成。
- 周计划编辑由页面上层会话持有，顶部保存和行内完成收取同一份草稿；切页不丢输入，失败保留文字与原始哈希，重复保存受控。快捷入口保留已有聊天草稿，连接完成不覆盖后来输入的文字。
- 首页、航线、资料和设置补齐读取失败、空数据、缓存时间、长地址、大字与窄窗呈现；技术配置进入次级区域。

## 设计依据

使用 apple-design、swiftui-ui-patterns、swiftui-performance-audit 和 swiftui-view-refactor 的相关指导，复用系统控件、语义颜色和辅助功能，避免装饰性动画增加主线程负担。参考 Apple [Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)、[Feedback](https://developer.apple.com/design/human-interface-guidelines/feedback)。断点和排版尺寸是本应用的实现选择。
