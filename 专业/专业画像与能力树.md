# 专业画像与能力树

## 已核实项目事实

- 中方专业：数据科学与大数据技术（中外合作办学）。
- 英方专业：Biomedical Data Sciences（生物医学数据科学）。
- 培养模式：4+0，四年均在南昌大学学习；英方课程由伦敦玛丽女王大学派师资来南昌线下授课。
- 教学语言：中方专业基础课及英方课程采用全英文教学。
- 学位：满足双方毕业和学位条件后，南昌大学工学学士 + 伦敦玛丽女王大学理学学士。
- 目标能力：用数据科学和大数据技术解决生物医学领域实际问题。

## 课程地图

用户提供或学院专业页列出的方向包括：高等数学、医学人工智能、数据库原理、医疗传感器和物理、健康科学编程导论、Python/计算机语言与编程、大数据分析、机器学习与模式识别、健康医学数据概论、基础医学遗传学、细胞生物学；学院专业页还列出离散数学、生物信息学、深度学习、操作系统、云计算、计算机网络、临床试验、流行病与卫生统计学、生物医学仪器数据和诊断学、生物医学数据团队科研项目等。

## 五条能力线

### 1. 数学与统计

- 高等数学、离散数学、概率统计、线性代数。
- 目标产出：每章一页概念图、错题集、可复算的统计练习。

### 2. Python、SQL 与数据工程

- Python、NumPy、pandas、SQL、Git、数据清洗、可视化。
- 目标产出：至少一个带 README、数据字典和复现步骤的小项目。

### 3. 机器学习与医疗 AI

- 监督学习、深度学习、模式识别、评价指标、数据泄漏、可解释性。
- 目标产出：从基线模型到误差分析的完整实验记录。

### 4. 医学、生物与伦理

- 遗传学、细胞生物学、医学数据概论、医疗传感器、临床试验、医学伦理。
- 目标产出：能把一个医学问题转成数据问题，并写出数据来源、偏差和伦理风险。

### 5. 学术英语与科研

- 英文教材阅读、课堂听力、论文检索、方法复述、图表和口头汇报。
- 目标产出：每月一篇论文结构卡或英文课程术语表。

## 大一优先级

1. 绩点：专业前 3 是目标，先保护高学分数学、编程和英文专业课。
2. 英语：建立专业术语表和英文教材预习习惯。
3. 编程：从基础 Python 过渡到 pandas、SQL 和可复现项目。
4. 探索：医疗 AI 与生物信息各做一次小型项目，再决定大二科研主轴。
