# 背景提升清单（大一篇）

> 原则：绩点是地基，其他是加分项。任何活动不能与绩点冲突。

## 大一值得做
- [ ] 英语：四级一次高分通过；启动雅思资料里的 I 段内容打基础
- [ ] 竞赛试水（门槛低、性价比高）：
  - [ ] 全国大学生英语竞赛（NECCS）——仓库里已有官方指南手册
  - [ ] 医疗 AI/健康数据方向小项目（完成一个可复现数据分析项目）
  - [ ] 数学建模或数据分析类竞赛（届次和报名时间待联网核实）
  - [ ] 生物信息/生命科学类竞赛（具体赛事与专业匹配度待核实）
- [ ] 技能：Office 三件套熟练；Python 过渡到 pandas、SQL 和 Git
- [ ] 学生工作：1 个班委或社团核心职务即可，宁精勿滥
- [ ] 读完《保研200问》前半部分（了解游戏规则）

## 大一不做
- 不盲目报高价"保研辅导班"（信息都在仓库和学校通知里）
- 不堆积无含金量证书（与推免加分表无关的一律不考）
- 不参加超过 2 个社团

## 到大二前的里程碑
1. 四级通过且分数有竞争力
2. 至少 1 次正式竞赛经历
3. 联系上 1-2 位愿意带本科生的导师
4. 成绩排名稳定在前【待填】%
