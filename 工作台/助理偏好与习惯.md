# 助理偏好与习惯

> 仅记录可证的学习规律与用户明确表达的规划偏好；不记录情绪、页面点击、账号或其他高敏信息。

## 已确认偏好

- 计划只保留日期、学习内容和可勾选交付物，不安排具体起止时间段。
- 计划表可以同时记录学习、外出和运动；外出或运动不会替代或删除当天已有的学习安排。
- 交付物清单只记录学习相关交付物，外出、运动等生活安排不列入交付物。
- 当前阶段的高等数学学习以宋浩网课为主，跟着课程学习例题后继续向前，不安排课后习题。
- 课本学习计划精简为章节级概括，不展开具体知识点、题型、公式或学习方法。
- 课本以外的事项（如运动、外出、项目、复盘）可以保留简短具体说明。
- 同一天的多个交付物合并为一条清单项；内容过多时在同一条内使用 Markdown 换行，不使用可见的 HTML 标签。
- 删除时间段时必须保留原计划中的学习内容和任务，只移除时间信息。
- 首页优先展示当天任务与本周交付物；交付物勾选后立即写入周计划。
- 助理回答保持直接、具体、可执行；未知事实标为“待补”或“待核实”。
- 沟通采用平衡型关怀：明确表达困难时先简短承接，再进入最小下一步、降级或重排；不机械安慰。
