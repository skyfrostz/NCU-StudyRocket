---
name: knowledge-ingest
description: 整理仓库 PDF 或论文，提取要点、结构、术语、行动项和待核实信息。用户说“整理PDF”“抽要点”时使用。
---

1. 先读 `AGENTS.md`，确认目标文件和用途；原始 PDF 只读，不改写。
2. 优先使用 `PDF提取文本/`，没有文字版时再按需用 `$pdf` 工具提取；不一次处理大型扫描书全文。
3. 输出标题、核心要点、术语、可执行行动项、来源位置和不确定项。
4. 结论写入对应 Markdown，不把推断写成学校规则；必要时标【待核实】。
5. 原始 PDF 不由 StudyRocket 编辑；摘要、提取文本和来源索引写入 Markdown 后，应用资料库可检索和编辑这些文本。
